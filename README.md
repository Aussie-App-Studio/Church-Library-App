# Church-Library-App
Open-source Android kiosk & catalog app for church and community book libraries, featuring ISBN barcode scanning, self-service borrowing/returns, and offline peer-to-peer multi-tablet sync. Built with Kotlin & Jetpack Compose. No data collection, 100% transparent. No ads.

## Features
- **Self-Service Kiosk Mode:** Simple, accessible interface for church members to browse the catalog, borrow books, and return active loans.
- **ISBN Barcode Scanning:** Quickly catalog new books and look up covers/metadata via Google Books and Open Library.
- **Offline-First & Local Tablet Sync:** All records are stored locally in an on-device Room database with optional peer-to-peer synchronization across library tablets using Nearby Connections.
- **PIN-Protected Admin Dashboard:** Manage inventory, track active and overdue loans, configure borrow periods, and export/restore local JSON backups.
- **Multilingual Support:** Localized across 50+ languages for diverse congregations.
